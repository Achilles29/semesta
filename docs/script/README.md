# Produksi dimulai ulang

Naskah dan episode sebelumnya telah dihapus dari workspace. [Day 1 lengkap dengan narator](001-day-1-scenes.md) kini dapat diputar di studio: 26 shot, 89,98 detik, tiga pemeran dan 19 potongan suara. Warga menentukan pembangunan, acara, aturan, dan kegiatan. Dokumen memuat timeline implementasi, latar, sumber suara, dan batas pemeriksaan.

Day 1 otomatis terbuka pada kunjungan baru atau draf kosong lama. Draf berisi suntingan dipertahankan; pilih **Day 1 lengkap · dengan narator** untuk membuka ulang versi bawaan. Di peta jelajah, **Tonton Day 1** membuka pemutar di Balai Produksi tanpa admin. [JSON scene](day1-scenes.json) dan [SRT](day1-subtitles.srt) dapat diunduh. Oke Gas dari file pengguna sudah terpasang pada pembuka/penutup. Hasil visual/audio dan MP4 masih perlu ditinjau di browser sebelum publikasi.

Panduan sistem: [Studio produksi](../PRODUCTION_STUDIO.md).
