# Avatar V2 asset library

This library is separate from `public/models/characters/` and is not loaded by the game. It contains schemas, target manifests, reports, and empty category folders only; there are currently no V2 character or modular GLB assets. Target paths in `semesta_character_manifest.json` are not files.

Start with a licensed, genuinely modeled source mesh. Review provenance and the V2 style guide first. Run the read-only host audit for an existing GLB or the Blender inspection script for GLB/FBX/OBJ/Blend sources. Export is opt-in, refuses replacement by default, and is restricted to this library. No automatic decimation, retopology, weight painting, retargeting, or artistic approval occurs.
