Jalan/lari merupakan klip di tempat. Saat karakter dipindahkan di dunia game, kecepatan geraknya perlu mengikuti metadata klip agar kaki tidak bergeser terhadap tanah. Kandidat belum dipromosikan ke game.

Gerakan dan variasi pakaian

Pemeriksaan file ekspor

File GLB kandidat diimpor kembali dan dirender untuk memeriksa hasil yang akan dimuat runtime.

Hasil uji

1,280 kombinasi tubuh/pakaian, 240 kombinasi kepala/aksesori, dan 8,385,960 sampel vertex pada 11 klip lulus pemeriksaan numerik. Bobot skin, independensi antar-instance, serta konfigurasi tersimpan diperiksa.

Enam klip lama mempertahankan transform attachment. Walk/Run sengaja berubah. Pijakan sole diuji pada sampel fase menapak untuk karakter acuan; tes ini tidak menjamin semua pakaian bebas clipping.

Batas kandidat dan sumber

Deformasi ekstrem di sela jari, bahu, panggul, serta pakaian lama masih bisa memerlukan pemolesan manual. Rok/sarung belum memakai simulasi kain. Pose duduk tidak menyertakan kursi. Tidak ada solver pijakan untuk medan tidak rata, atlas tekstur, atau LOD baru.

Perkiraan draw call karakter acuan: 28. FPS GPU dan interaksi browser belum diverifikasi otomatis. Ekspor tetap memakai morph tanpa delta normal seperti V12. Kualitas visual browser perlu ditinjau pada perangkat sasaran.
