# Referensi karakter gameplay klasik

Folder ini berisi turnaround raster untuk referensi pemodelan 3D. Setiap lembar menampilkan karakter yang sama dari depan, samping kiri, belakang, dan tiga-perempat depan dalam pose netral.

## Isi

- `harvest-moon/ps1-back-to-nature-pete-turnaround.png` — Pete, gaya model gameplay PS1 dengan cap biru, saputangan merah, overall, sarung tangan putih, dan sepatu kerja.
- `harvest-moon/ps2-save-the-homeland-hero-turnaround.png` — protagonis *Save the Homeland*, gaya model gameplay PS2 dengan cap, overall, sarung tangan merah, dan tas selempang.
- `suikoden-iii/hugo-turnaround.png` — Hugo dalam gaya model gameplay PS2, lengkap dengan rambut dua warna dan pakaian Karaya.
- `final-fantasy/ff7-cloud-turnaround.png` — Cloud versi field model PS1: proporsi super-deformed, pakaian ungu, dan pauldron kiri.
- `final-fantasy/ff8-squall-turnaround.png` — Squall versi field model PS1 dengan jaket hitam berkerah bulu, sabuk, dan proporsi asli permainan.
- `final-fantasy/ff9-zidane-turnaround.png` — Zidane versi gameplay PS1 dengan vest biru, celana longgar, sarung tangan, sepatu bot, dan ekor.
- `republik-wkwkwk/warga-chibi-aktif-turnaround.png` — gambar empat sudut avatar warga yang sedang dipakai game, dibuat dengan acuan `public/models/characters/warga-chibi-preview.png` dari model `warga-chibi-base.glb`.

## Batas pemakaian

File PNG ini adalah referensi visual hasil generatif, bukan mesh, rig, animasi, atau aset hasil ekstraksi dari gim asli. Sebelum dipakai sebagai aset produksi, buat model 3D baru, periksa ulang proporsi dari beberapa tangkapan gameplay, lalu lakukan uji siluet pada kamera permainan.

Gambar avatar Republik WkWkWk merupakan interpretasi dari preview model lokal. Untuk bentuk mesh yang persis, lihat langsung `public/models/characters/warga-chibi-base.glb`.

## Ringkasan prompt produksi

Semua gambar dibuat sebagai turnaround ortografis empat sudut, satu desain konsisten, seluruh tubuh terlihat, pose A netral, latar abu-abu polos, pencahayaan studio netral, tanpa senjata, UI, teks, logo, watermark, adegan aksi, atau gaya key art. Gaya render mengikuti batas visual konsol asal: low-poly PS1 untuk Pete/Cloud/Squall/Zidane dan low-poly PS2 untuk Hero/Hugo.
